## 0.2.34: 사망 음원과 추적 화면 원점

- `481a13/481b23`, 진영별 `4abbe8..4ac6b9`, `4e989a..4f2759`, `52eca4`는 유닛 사망 애니메이션 경로에서 플레이어 음성 인터페이스 `+2c`에 이벤트 4를 전달합니다. 이전 수정은 최종 공간 음성 호출만 바꿔, 그 전에 있는 `52110a/53d5a7` 소유권 검사와 `52139e` 음성 채널 검사에 막힐 수 있었습니다.
- 재생 전용 `521090/53d570` 진입 후킹에서 이벤트 4만 별도로 처리합니다. 원본 `b38f50` 유형별 사망 음원 범위와 `b39a52` 사용 가능 표시를 확인하고 효과음 볼륨 `b8a1e0`으로 공간 재생합니다. 게임 난수·플레이어 응답 캐시·선택·유닛 상태는 변경하지 않습니다. 다른 응답은 기존 경로로 보내 대사 음소거를 유지합니다. AU01 로그에 사망 이벤트/음원 제출 횟수를 추가했습니다.
- 추적 시 글로벌 원점만 바꾸면 지형이 다른 위치에 남았습니다. 렌더 직전에 원본 `4d8e8d..4d8eec`와 같은 `67c5c0`, 두 `630930` 호출로 지형·오버레이 원점을 갱신하고 게임 `+9c4/+9c8` 표시 좌표를 동기화합니다. 네이티브 스크롤 입력/타이머 처리 이후 갱신하므로 수동 스크롤을 요구하지 않습니다.
- 네이티브 회귀 테스트: 다른 소유자의 사망 이벤트, 무효 음원 건너뛰기, 대사 볼륨 0에서 효과음 볼륨 유지, 두 난수/플레이어 캐시 보존, 추적 시작 즉시 지형·오버레이·표시 좌표 일치. Python 42개 테스트 및 빌드 통과. 실제 화면과 청취 검증은 미확인입니다.
