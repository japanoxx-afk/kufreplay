## 실행

프로젝트 폴더 `C:\Users\seo\Documents\ChatGPT\킹덤언더파이어`의 `KUFReplayLauncher.exe` 또는 `dist/0.2.21/KUFReplayLauncher.exe`를 실행합니다. 빌드된 실행 파일에는 엔진 DLL/주입기가 포함되며 Python 설치가 필요 없습니다. 소스 실행은 먼저 `native/build.cmd`를 빌드하고 `Launch.cmd`를 실행합니다.

백그라운드 저장 중 버튼 요청은 대기열에서 처리하며 중복 실행 요청을 합칩니다. 종료 감시기는 게임의 종료 잔여 프로세스만 정리하며 LocusGameChain.exe에는 종료 요청을 보내지 않습니다. 재생 중 `I`는 현황판, `U`는 전체 HUD와 오른쪽 세로 UI, `1/2/4`는 시뮬레이션 배속입니다. HUD를 숨기면 오른쪽 자리까지 지형을 그립니다. 건물·유닛 클릭은 원래 플레이어 선택과 분리되어 native 초상화·이름·체력·건물 진행 정보를 표시합니다.

실제 검증: 우측 상단 작은 현황판, HUD 숨기기/지형 확장, 전체 미니맵, 상대 건물 초상화·생산 진행, 최종 상태 일치. 업그레이드·연구는 원래 게임의 진행 표시 경로를 관전자 선택에 연결했으며 해당 작업 중인 실제 경기 검증은 남아 있습니다. 투명·공중·지하 유닛, 모든 효과음 종류의 청취, 유닛 초상화 애니메이션, 영웅/쉬는 농부 알림, 다른 해상도는 추가 실전 검증이 필요합니다.

0.2.6은 커스텀 경기 결과/메뉴 전환 감지, Alt+F4 마감, 프로세스 종료 후 검증 가능한 기록 앞부분 자동 복구를 제공합니다. 복구는 디스크에 남은 구간만 대상으로 하며 마지막 배치 직전 경계에서 종료합니다. 재생도 Steam으로 실행하며 기존 게임이 실행 중이면 한국어 안내를 표시합니다. 상세 검증 범위는 `docs/ENGINE_NATIVE.md`를 참고하세요.

하단 오른쪽 **게임 실행 (Steam)** 버튼은 설치된 App ID 2183600을 `steam://rungameid/2183600`으로 실행하고 새 게임 프로세스에 기록 엔진을 연결합니다. 기존 게임을 먼저 닫고 런처의 **기록 엔진 연결 완료** 안내를 확인하세요. 초기 네트워크 계정 안내창에서는 **아니요**를 누르세요. 싱글플레이 경기 후 게임 창을 정상 종료하면 자동 저장합니다. 실제 경기 기록·정상 파일 포장과 목록 등록을 확인했습니다. 싱글 커스텀 자동 재생과 관전자 카메라 이동은 실제 게임에서 확인했습니다.

- 게임 경로 지정 및 원본 게임 실행
- 실험용 싱글플레이 자동 기록과 정상 완료 기록 포장
- 기본 최근 20개, 1~10000개 보관 설정: 정상 기록 및 일반 항목 가져오기에 적용
- 날짜·시간 파일명, 영구저장/해제, 외부 리플레이 가져오기

## 업데이트

버튼은 `japanoxx-afk/kufreplay`의 최신 정식 GitHub Release를 확인합니다. 현재보다 높은 `vMAJOR.MINOR.PATCH` 버전에 `KUFReplayLauncher.exe`와 `KUFReplayLauncher.exe.sha256`이 있어야 다운로드합니다. 크기 제한과 SHA256 검사 후 공통 데이터 폴더의 `Updates`에 저장하고 해당 폴더를 엽니다. 사용자가 새 실행 파일을 실행합니다. SHA256은 전송 무결성 검사이며 코드 서명이나 독립된 게시자 인증을 대신하지 않습니다.

정식 배포 파일은 GitHub Releases에서 제공합니다. 릴리스가 없으면 버튼에 해당 이유가 표시됩니다.
